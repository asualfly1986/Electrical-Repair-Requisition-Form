# ระบบสร้างใบเบิกของแก้ไฟ - การไฟฟ้าส่วนภูมิภาค (PEA Requisition App)

เว็บแอพพลิเคชันสำหรับสร้างและพิมพ์แบบฟอร์ม **ใบเบิกของ (ฉบับที่ 1 ส่งให้คลังพัสดุจ่าย)** สำหรับงานบริการแก้กระแสไฟฟ้าขัดข้องและบำรุงรักษาระบบไฟฟ้าของการไฟฟ้าส่วนภูมิภาค (PEA) เชื่อมต่อฐานข้อมูลจาก Google Sheets และพิมพ์ลงกระดาษ A4 ได้ตรงตามสัดส่วนมาตรฐาน

---

## ⚡ คุณสมบัติหลัก (Features)

1. **เชื่อมต่อฐานข้อมูล Google Sheets อัตโนมัติ**:
   - เชื่อมต่อกับ Google Spreadsheet ของ กฟภ.
   - รองรับการซิงค์ข้อมูลแบบ Real-time, การนำเข้าไฟล์ CSV/Excel และฐานข้อมูลพัสดุมาตรฐาน กฟภ. ในตัวกว่า 60+ รายการ
2. **ระบบค้นหาและจัดการรายการเบิก (Smart Requisition & Basket)**:
   - ค้นหาด้วยรหัสพัสดุ หรือชื่อพัสดุภาษาไทยแบบ Real-time
   - กรองตามหมวดหมู่ เช่น ฟิวส์/ดรอปเอาท์, สายไฟฟ้า, คอนเนคเตอร์, อุปกรณ์หัวเสา, เทป/ฉนวน, มิเตอร์
   - ปรับเพิ่ม/ลดจำนวนพัสดุได้ง่าย พร้อมแสดงหน่วยนับอัตโนมัติ
   - รองรับการเพิ่มรายการพัสดุพิเศษนอกตาราง
3. **แบบฟอร์มพิมพ์ใบเบิก A4 ตรงตามต้นฉบับ 100% (Pixel-Perfect Print & PDF)**:
   - ตราสัญลักษณ์ กฟภ. (PEA Official Emblem)
   - หัวตาราง: ฉบับที่ 1, กฟฉ.1, แผนกปฏิบัติการระบบไฟฟ้าฯ, กฟส.ขอนแก่น 2, วัตถุประสงค์งานแก้ไฟมะลิวัลย์
   - ลายน้ำบอกเลขหน้า ("หน้า 1") กลางตารางตามภาพต้นฉบับ
   - ช่องลงนาม 4 ตำแหน่ง: ผู้เบิก, ผู้ตรวจ, หัวหน้าคลังพัสดุ, ผู้อนุมัติ
   - สั่งพิมพ์ (Print to A4) หรือบันทึกเป็นไฟล์ PDF ได้ทันทีโดยไม่ตกขอบ
4. **บันทึกการตั้งค่าและประวัติใบเบิก**:
   - บันทึกชื่อผู้ลงนามและข้อมูลหน่วยงานไว้ล่วงหน้า
   - บันทึกประวัติใบเบิกย้อนหลังเพื่อเปิดดูหรือพิมพ์ซ้ำได้

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดใช้งานผ่านเว็บเบราว์เซอร์โดยตรง (แนะนำ)
- ดับเบิ้ลคลิกเปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge หรือเว็บเบราว์เซอร์ใดก็ได้

### วิธีที่ 2: รันผ่าน Local Web Server (Python)
เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
python -m http.server 3000
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

## 📋 วิธีตั้งค่าสิทธิ์แชร์ Google Spreadsheet เพื่อให้แอพดึงข้อมูลได้

1. เปิดเอกสาร Google Sheets ของท่าน
2. กดปุ่ม **"แชร์" (Share)** ที่มุมขวาบน
3. ในส่วน **การเข้าถึงทั่วไป (General access)** ให้เปลี่ยนจาก *จำกัด (Restricted)* เป็น **"ทุกคนที่มีลิงก์ (Anyone with the link)"** และตั้งค่าสิทธิ์เป็น **"มีสิทธิ์อ่าน (Viewer)"**
4. คัดลอกลิงก์มาวางในช่อง **"เชื่อมต่อ Google Sheet"** ในแอพ แล้วกด **"ซิงค์ข้อมูล Google Sheet"**
